# HuggyWuggyAddonTest1

HuggyWuggyAddonTest1 is a Minecraft plugin that introduces the iconic Huggy Wuggy monster from Poppy Playtime. This plugin is designed to spawn the Huggy Wuggy monster and allow players to interact with it, creating a unique and creepy experience in your Minecraft world. The plugin is built for Minecraft Bedrock Edition and is compatible with version 1.21.

## Install

1. Download the HuggyWuggyAddonTest1 plugin from the GitHub repository.
2. Place the downloaded JAR file into the plugins folder of your Minecraft server.
3. Start or restart your Minecraft server to load the plugin.

## Use

1. Once the plugin is installed and the server is running, you can use the following commands:
   - `/spawnhuggywuggy` - Spawns the Huggy Wuggy monster in the world.
   - `/hug` - Hugs the player, providing a unique interaction with the Huggy Wuggy monster.
